# Hi, I'm ZyoVex 👋

I’m a software developer who builds resilient services, automation workflows, and player-facing tools. My work spans **TypeScript/Node.js** backends and the **Java/Minecraft** ecosystem, with an emphasis on practical delivery under real-world constraints.

## What I build

- **Backend automation & bots** — stateful messaging experiences, background jobs, content workflows, and operational tooling.
- **Resilient deployments** — systems designed to run efficiently in constrained hosting environments such as cPanel.
- **Minecraft server tooling** — Java plugins, proxy/bridge integrations, and quality-of-life improvements for server communities.

## Core stack

## How I approach engineering

- Start with the real user constraint, then choose the smallest dependable architecture.
- Keep service boundaries clear even when deployment needs to stay simple.
- Make operational state visible through logs, queues, and lightweight dashboards.
- Treat configuration and secrets as first-class production concerns.
